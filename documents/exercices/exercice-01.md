# Exercice 1 — Découvrir Markdown 

## Questions 

1. Qu'est-ce qu'un dépôt GitHub ? 
2. À quoi sert un fichier README ? 
3. Quelle extension utilise un fichier Markdown ? 

## Réponses 

1. Un dépôt permet de ranger les fichiers d'un projet. 
2. Un README présente le contenu et l'objectif du projet. 
3. Un fichier Markdown utilise l'extension `.md`.
